# SYZOJ 提交监视器

在任意网页悬浮展示目标 SYZOJ OJ 指定用户（支持多人）的实时提交状态（状态 / 得分 / 提交人 / 题目）。

一个 Chrome（Manifest V3）浏览器扩展，用于在 OI/ACM 训练时实时盯住一个或多个用户的提交动态。

## 功能特性

- **悬浮面板**：注入到任意网页右下角，通过 Shadow DOM 隔离样式，不改动宿主页面
- **多人监测**：同时监测多个用户，提交合并进同一面板，按提交时间倒序展示，提交人列区分归属
- **实时刷新**：每 20 秒并行轮询所有目标用户的最新提交
- **多字段展示**：状态（Accepted / Wrong Answer / Judging…）、得分、提交人、题号与题名
- **加载更多**：翻页拉取更早的历史提交（兼容普通分页与快速分页），多人时按「最旧记录」优先翻页
- **多域名容错**：主备两个 OJ 域名自动切换
- **可拖动 / 可折叠**：面板位置自动记忆

## 安装

1. 下载或克隆本仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本目录
5. 点击扩展图标，输入要监测的 OJ 用户名并保存

## 使用

- 点击工具栏图标 → 输入目标用户名 → 保存
- 用户名输入格式：每行一个，或用逗号（中英文）、空格分隔；保存时自动去重并规范为每行一个
- 悬浮面板出现在当前页面右下角，实时显示这些用户的提交（按时间倒序合并）
- 拖动标题栏可移动面板，点击 ▁/□ 可折叠 / 展开
- 「加载更多」可拉取更早的提交记录

## 目标站点与数据说明

本扩展默认监视以下 SYZOJ 站点：

- `https://in.7fa4.cn:8888`
- `https://jx.7fa4.cn:8888`（备用）

数据抓取说明：

- 扩展只请求「提交列表页」`/submissions`，**不会**访问单个提交详情页
- 请求携带你在浏览器中已登录该 OJ 的 Cookie（`credentials: 'include'`）；若站点要求登录，请先在浏览器打开并登录目标 OJ 后再使用
- 所有抓取在 background service worker 中完成，用于规避跨域限制

## 技术架构

- Manifest V3 + background service worker
- 数据流：`content script`（渲染）←→ `background`（抓取）←→ 目标 OJ
- 悬浮面板使用 Shadow DOM 隔离样式，不改动宿主页面
- 提交数据解析：从页面 `const itemList = [...]` 中提取 JSON，用括号配对法避免题名含 `]` 时被误截断
- 多人抓取：`FETCH_ALL` 并发抓取各用户第一页，`FETCH_MORE` 按需翻指定用户的下一页

## 文件结构

```
.
├── manifest.json   # 扩展清单（MV3）
├── background.js   # service worker：抓取、多域名容错、多人消息协议
├── content.js      # 悬浮面板注入、渲染、拖动、轮询、多人合并排序
├── popup.html      # 设置弹窗
├── popup.js        # 弹窗逻辑（多用户输入解析）
└── popup.css       # 弹窗样式
```
